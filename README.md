# PRODIGY_WD_01

## Task 1: Interactive Navigation Menu Website

This task is a part of my **Web Development Internship at Prodigy InfoTech**.  
The assignment was to build an **interactive navigation menu** which sticks at the top of the page, changes its styles on scrolling, and also has hover effects on menu items.

---

## ✨ Features
- Sticky navigation bar displayed in all sections
- Gradient background with dark mode effect on scrolling
- Hover effects with smooth underline transitions
- Responsive design with hamburger navigation menu for mobile
- Floating bubbles with gradient background
- Glassmorphism cards with hover effect

---

## 🛠️ Technologies Used
- **HTML5** → Layout and content
- **CSS3** → Design, animations, and responsive layout
- **JavaScript (ES6)** → Interactivity, scroll-based dark mode effect

---

## 📂 Project Structure
- `index.html` → Website layout  
- `style.css` → Styles and animations  
- `script.js` → Scroll based effects and interactions  

---

## 📸 Output Preview
A modern and professional landing page with:
- Animated navigation bar
- Hero section with gradient background and call-to-action button
- Scrolling sections with floating bubbles
- Interactive service cards
- Branding footer
